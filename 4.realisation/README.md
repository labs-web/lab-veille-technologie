# Consignes de Réalisation : Étape 4 - Banc d'Essai & Expérimentation

Ce dossier est l'espace exclusif de l'apprenant pour réaliser les tests, le banc d'essai et l'expérimentation de la veille technologique.

> ⚠️ **Règle Pédagogique Inviolable :** L'agent IA n'écrit aucun code ni aucune analyse dans ce dossier. C'est à vous, apprenant, de mener les expérimentations et d'y déposer vos résultats.

---

## 🎯 Travaux à Réaliser par l'Apprenant

### 1. Analyse du gisement `stateofai.dev`
- Visiter et explorer la plateforme `stateofai.dev`.
- Extraire 3 insights technologiques majeurs pertinents pour notre fil rouge (ex: modèles compacts, agents de code, outillage d'évaluation).
- Créer une note d'analyse synthétique dans ce dossier (ex: `analyse-stateofai.md`).

### 2. Investigation des compétences IA de veille existantes
- Explorer les registres open-source de skills (ex: `skills.sh`, dépôts GitHub de briques agentiques).
- Télécharger ou étudier au moins 2 skills anglophones de veille (ex: `tech-watch`, `trend-scout`, `arxiv-digest`).
- Analyser leur prompt système, leurs outils requis (recherche web, lecture RSS, filtres) et leurs faiblesses.

### 3. Banc d'essai étalon (Testbench)
- Poser un sujet de veille test (ex: *"Dernières versions stables et évolutions de Laravel et Alpine.js"*).
- Exécuter la veille selon le cycle théorique (Cibler ➔ Collecter ➔ Filtrer ➔ Analyser ➔ Diffuser).
- Documenter le temps passé, les sources retenues et la qualité des résultats obtenus.

### 4. Bilan pour la spécification du Skill
- Noter les règles impératives que notre futur skill `tech-watch` devra respecter pour assister `AgentDev`.
